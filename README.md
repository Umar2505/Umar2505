### About me

I'm a student developer who likes to build full, working systems rather than isolated exercises — a project usually comes with a frontend, a backend, and a model or a device on the other end of it. My work spans web apps, applied machine learning, and embedded/IoT simulation, and I care about clean architecture as much as the end result.

- 🔭 Currently exploring agentic LLM systems and privacy-preserving AI
- 🧠 Comfortable across the stack: React/TypeScript on the frontend, Python (Flask) on the backend, and ML/DL in between
- 🌱 Interested in embedded systems and hardware simulation
- 📍 Based in Oulu, Finland
